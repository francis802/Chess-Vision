# Pipeline walkthrough

This document expands on the end-to-end flow implemented in
[`../notebooks/board_and_pieces_pipeline.ipynb`](../notebooks/board_and_pieces_pipeline.ipynb).

## 1. Board localization

Three strategies were implemented and compared:

- **Corner-regression CNN** — a CNN (EfficientNet/ResNet backbone) regresses the
  four board corners directly. Metrics: [`../metrics/corner_detection/`](../metrics/corner_detection/).
- **Mask R-CNN segmentation** — instance segmentation of the board surface.
  It failed to converge on this dataset (validation IoU ≈ 0) and was discarded.
  Training code: [`../src/train_board_maskrcnn.py`](../src/train_board_maskrcnn.py);
  metrics: [`../metrics/board_mask_maskrcnn/`](../metrics/board_mask_maskrcnn/).
- **U-Net segmentation (final)** — a lightweight U-Net trained with a combined
  binary-cross-entropy + Dice loss. Best validation Dice ≈ 0.996. The predicted
  mask is used to estimate the board homography.
  Metrics: [`../metrics/board_unet/`](../metrics/board_unet/).

## 2. Rectification

From the board mask / corners, a homography is estimated and the image is warped
to a canonical top-down view. The board is then rotated to a consistent
orientation before grid mapping.

## 3. Piece detection

A YOLO model (YOLOv8 / YOLO11 backbone) is fine-tuned on the chess dataset to
detect pieces and board corners. The 13-class label set is defined in
[`../data/pieces.yaml`](../data/pieces.yaml). The fine-tuned weights ship as
[`../models/yolo_piece_detection.pt`](../models/) and
[`../models/yolo_board_detection.pt`](../models/).

## 4. Grid mapping & digital twin

The rectified board is split into an 8×8 grid. Each YOLO detection is projected
through the homography and assigned to its square, producing a board matrix that
is rendered as a 2-D diagram using the sprites in
[`../data/pieces_png/`](../data/pieces_png/).

The 9×9 grid-point pseudo-labels used by the direct grid-regression experiment are
generated by [`../notebooks/grid_generation.ipynb`](../notebooks/grid_generation.ipynb)
into `../data/grid_labels/`; metrics live in
[`../metrics/grid_regression/`](../metrics/grid_regression/).

## Auxiliary task — piece counting

Independently, the number of pieces on a board is estimated:

- **Classification** — modelled as 33-way multiclass (0–32 pieces):
  [`../notebooks/piece_counting_classification.ipynb`](../notebooks/piece_counting_classification.ipynb).
- **Regression (final)** — EfficientNet-B0 with a `ScaledSigmoid` head and Huber
  loss, trained on the full dataset:
  [`../notebooks/piece_counting_regression.ipynb`](../notebooks/piece_counting_regression.ipynb).
  Inference script: [`../src/count_pieces_regression.py`](../src/count_pieces_regression.py).
  Earlier iterations are kept under `../notebooks/experiments/`.
